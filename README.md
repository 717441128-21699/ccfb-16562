# 花楼织锦 · 挑花结本

一个以真实花楼织机结构为模型的织锦解谜游戏。你是花楼机上的挑花匠:
把意匠图上的纹样,一纬一纬挑成花本上的耳子线;织机照花本提综下压,
彩纬浮面显花——挑错一根,整幅花纹就错位。

## 运行

```bash
npm install
npm run build      # 打包出 dist/bundle.js
```

然后直接用浏览器打开 `index.html` 即可(单文件 IIFE 打包,file:// 可运行)。

```bash
npm test           # 冒烟测试:关卡生成 / 织造对照 / 纬浮 / 耳子线 / 性能
```

## 玩法

- **关卡选择页**:七种传统纹样(菱格朵梅、万字不到头、祥云、缠枝莲、
  宝相团花、八达晕、妆花云龙大缎),规格从 96×96 到 2000 经 × 1000 纬。
- **挑花结本页**:在 W×P 的花本格子上结耳子线。意匠图垫底(可开关),
  结/拆笔、镜像笔、左右循环铺行、上下循环铺幅、整纬复制/镜像复用。
  高级关卡在左侧梭道条上换梭配彩纬。
- **织机页**:花楼机示意(花本帘、耳子线、综丝、梭子)+ 逐纬织造动画,
  1~256 纬/帧可调,可瞬织。
- **织物成品页**:布面放大检视,纬浮超标(勾丝)标红、错位标橙,
  按一致度 / 纬浮 / 耳子线数定一至三星,可点错位纬号跳回挑花页修改。

## 规则模型(src/weave.ts)

- 花本结子处:该经此纬沉下,彩纬浮于面上显花;未结处由地综织地组织
  (平纹 / 二一下斜纹 / 三一下斜纹),经与地纬交织。
- **纬浮**:彩纬连续浮长(同行连续结子数)超过关卡上限即勾丝,须开间丝点。
- **耳子线**:内容相同或左右镜像相同的花本行只算一根——对称与循环纹样
  可以复用花本,少挑一半。
- **自由行**:意匠图只画满色的彩带,间丝点由玩家自行留空;空结过多
  (彩带没织出)判错位,结太满则纬浮勾丝。
- 全部交织点由花本确定性织出;2000×1000 全幅织造 <10ms,
  逐纬动画每帧(16 纬)<0.3ms。

## 目录

```

src/levels.ts     七种传统纹样的程序化生成与关卡规格
src/editor.ts     挑花结本页(花本编辑)
src/loom.ts       织机页(逐纬织造动画)
src/result.ts     织物成品页(对照、标记、定星)
src/levelsPage.ts 关卡选择页
src/state.ts      进度与星级存档(localStorage)
src/render.ts     布面像素渲染辅助
test/smoke.ts     冒烟测试
```
